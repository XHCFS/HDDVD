# HD DVD-Video Standard Content Format Specification (archival)

A specification of **HD DVD-Video Standard Content**, the "Category 1" playback mode.
Standard Content is the DVD-Video navigation model (Video Manager, Video Title Sets,
Program Chains, cells, the navigation-command VM) evolved to high definition.

This set is **archival and out of scope for `libhddvd`**. Almost no retail HD DVD ships
Standard Content. A structural survey of 120 disc images found 1 Standard, 119
Advanced, and 0 mixed [11]. The product target, a VLC HD DVD player, uses Advanced
Content, specified in the companion set. This set exists to preserve the
Standard-Content reverse engineering and to document the format completely for the
record. It is written to the same evidence standard as the Advanced set but rests
almost entirely on a single specimen, so its dominant evidence grade is SINGLE. See
[08_gaps.md](std_08_gaps.md).

## What Standard Content is

Standard Content is DVD-Video widened for HD. The DVD Forum defined it so an
inexpensive player with no Internet connection and no interactive engine could play an
HD disc while staying structurally compatible with DVD-Video [1]. It keeps the entire
DVD navigation model and adds HD codecs.

| Aspect | DVD-Video | HD DVD Standard Content |
|---|---|---|
| Navigation model | VMG, VTS, PGC, Cell, PTT, command VM | Same, with widened fields |
| Content directory | `VIDEO_TS/` | `HVDVD_TS/` |
| Info file | `VIDEO_TS.IFO`, `VTS_nn_0.IFO` | `HV000I01.IFO`, `HVnnnI01.IFO` |
| Media object | `.VOB` | `.EVO` (Enhanced Video Object) |
| Video codecs | MPEG-2 | MPEG-2, VC-1, H.264/AVC |
| Audio codecs | AC-3, DTS, LPCM, MPEG | Above plus DD+, TrueHD, DTS-HD |
| Interactivity | VM plus NV_PCK highlight buttons | Same; no HDi |
| Filesystem | UDF 1.02 with ISO bridge | UDF 2.50 with Metadata Partition |
| Encryption | CSS | AACS |

The design goal is stated plainly in the patents. Advanced Content *removes* the
layered structure: "No Title, no PGC, no PTT and no Cell. No support of Navigation
Command and UOP control" [1]. Standard Content is the mode that keeps all of it.

## About this specification

The content was reconstructed from three source classes, and every fact carries its
evidence.

1. **Primary specifications.** The Toshiba patents transcribe the unpublished DVD Forum
   books closely, including byte-level `RBP` (Relative Byte Position) tables and 138
   drawing sheets. Cited `[1]`, `[2]`, `[3]` in [09_references.md](std_09_references.md).
2. **One reference disc.** `RESERVOIR_DOGS` (Reservoir Dogs 15th Anniversary, PAL,
   `hd-dvd_archive_03`) is the only Category 1 image in the 120-disc corpus [11]. It is
   unencrypted, which is why its IFOs read as plaintext, and was authored with Sonic
   Scenarist SCA 4.2. Every byte-level claim comes from this disc unless a patent table
   corroborates it.
3. **DVD-Video prior art.** libdvdread `ifo_types.h` and libdvdnav `vm/vmcmd.c`, since
   the format is a delta from DVD-Video.

**Evidence grades.** **VERIFIED** means a patent RBP table and the disc agree, or the
claim is chain-validated or arithmetically closed. **SINGLE** means it was read from
the one specimen with no patent table and no second disc, so it could be a Scenarist
authoring artifact rather than a format property. **INFERRED** means a fail-closed rule
reasoned from a source. **OPEN** means not yet decoded. Because there is only one disc,
SINGLE is the honest ceiling for most of this set.

## Conventions

| Item | Rule |
|---|---|
| Endian | IFO structures are big-endian, as in DVD-Video. UDF descriptors are little-endian. |
| Sector / pack | 2048 bytes. |
| RBP | Relative Byte Position, an offset from the start of the structure (patent term). |
| Identifiers | 12-byte ASCII, DVD convention: `HVDVD-VMG100`, `STANDARD-VTS`. |
| Version word | `VERN` `0x0010` is specification 1.0. |
| Drift | Patent identifiers differ from the disc (`HDDVD_TS` versus `HVDVD_TS`). The disc wins. |
| Command word | The DVD-Video 8-byte VM command word rotated right 16 bits (§4). |
| Citations | Inline `[n]` resolves in [09_references.md](std_09_references.md). Grades are evidence strength. |
