About HD DVD Advanced Content
                HD DVD is a next-generation 15 GB optical disc format (30 GB for dual layer
                discs). HD DVD discs can be authored as either Standard Content or Advanced
                Content. Standard Content is an extension to the DVD-Video format; Advanced
                Content offers a whole new level of interactivity.

                Advanced Content includes:

                • Playlist-based navigation

                • Primary and Secondary Video streams with picture-in-picture

                • Advanced Applications with 32-bit images and 8-bit alpha channels for
                  interactive menus, animations, and slideshows

                • Advanced Subtitles with text-based titling

                • Internet connectivity for dynamic content

                Note: Scenarist Advanced Content supports authoring only Advanced Content.
                To author Standard Content, you can use the Sonic Scenarist Standard Content
                module authoring system.

Installing Scenarist Advanced Content
       This section documents how to install the Scenarist Advanced Content software
       and dongle. The included Sonic dongle must be attached to your computer when
       you run the Scenarist Advanced Content software. When launching the program
       the first time, you are prompted to activate the software by entering an Activator
       Code. The Activator Code is emailed to you after Sonic receives your registration
       information.

       Note: Make sure not to attach the Sonic dongle until after the Scenarist
       Advanced Content software and Sentinel dongle drivers have been installed.


       To install and activate Scenarist Advanced Content:
       1 Insert the Sonic Installation disc and run the Setup program.

       2 Follow the on-screen instructions. Restart Windows if prompted.

       3 Run the Setup program for the Sentinel dongle drivers. Follow the on-screen
         instructions.

       4 Attach the Sonic dongle to your computer’s USB port.

       5 From the Windows Start menu, choose All Programs > Sonic > Scenarist
         Advanced Content > Scenarist Advanced Content.

Scenarist Advanced Content workflow
                The following procedure outlines the basic workflow for authoring projects in
                Scenarist Advanced Content. These steps are documented in greater detail in the
                remaining chapters.

                Authoring in Scenarist Advanced Content includes the following basic steps:

                1 Assemble and import assets

                     a Prepare any assets required for the project, including video and audio
                       files, subpicture scripts, and Advanced Content files.

                     b In Scenarist Advanced Content, create a new project and import the
                       video, audio, and Advanced Content files into the Palette window.

                2 Prepare EVOBS

                     a In the EVOBs window, create as many EVOBs as required.

                     b Select an EVOB and drag video and audio files to the video and audio
                       tracks of the timeline, repeating this task for each of the EVOBs in the
                       project. Select subpicture tracks and import subpicture scripts as desired.

                     c Create additional EVOB Segments for those EVOBs that will be used in a
                       single Title or in multiple Titles, with a different duration in each.

                     d Set In and Out Points for each EVOB Segment as required. The default
                       duration of an EVOB Segment is the entire EVOB.

                     e Use the Attributes window to set the names of the EVOB files on the final
                       disc.

                     f Set the order of EVOB files on the final disc by ordering EVOBs within
                       the EVOBs window.
                                             Scenarist Advanced Content workflow   13



3 Create Titles and Playlists

    a Select a Title within a Playlist in the Project window, and drag an EVOB
      Segment from the EVOBs window onto one of the EVOB tracks in the
      Title timeline (Primary Audio Video, Substitute Audio Video, Substitute
      Audio, or Secondary Audio Video). Select Titles in the Project window to
      display them in the Title Timeline window.

    b Add Advanced Content to Titles by selecting a Title in the Project
      window and dragging clips from the Palette window into the Advanced
      Subtitle and Application tracks in the Title Timeline window. Use the
      Attributes window to set properties for the Advanced Content clips.

    c Add chapters and events to Titles in the Title Timeline window as
      needed.

    d Assign the First Play Title for the Playlist in the Project window.

    e Create additional Playlists as required, by duplicating an existing one, or
      creating a new one.

4 Set up Track Navigation, audio, and subtitle mapping

    a In the Track Navigation list dialog, set the video, audio, and subtitle
      attributes for each Title track available to the user during playback.

    b For each EVOB clip in the Title Timeline window, map audio and
      subpicture streams in the EVOB to audio and subpicture tracks in the
      Title. Make sure that the mapping corresponds with the order you have
      chosen for the track navigation list.

5 Add Playlist Applications

   Drag a Manifest file (.xmf), or an archive (.aca) containing a Manifest file,
   from the Palette window onto a Playlist in the Project window.
14   Chapter 2, Workflow and windows



                6 Configure final project settings

                     a Configure AACS settings in the Project Settings dialog.

                     b In the Additional Resources tab of the Project Settings dialog, add
                       Advanced Resource Files that an Application will load by means of a
                       script on an as-needed basis during playback (for example, large .wav
                       files associated with a game).

                7 Build, emulate, and pre-master

                     a Output the project to an HD DVD Advanced Content volume with the
                       Build command.

                     b Emulate the volume using the Preview engine.

                     c Using Scenarist Formatter, pre-master the volume to recordable media or
                       a DDP/CMF file set for replication.

       The Palette window displays the project’s assets, which can include media files

       into the Palette window. The tabs at the top of the window determine which
       assets are displayed: Media or Advanced Content. Assets can be displayed in a list
       or as thumbnails; when displayed in a list, the assets can be sorted.

                Using the Palette window

                To use the Palette window:
                1 To show or hide the Palette window, select Window > Palette or press F5.

                2 Click one of the following tabs to display the project’s assets.

                   Media Displays the project’s video and audio assets. When the Media tab is
                   selected, use the Show pop-up menu (Show All, Show Video, or Show Audio)
                   to determine which of these assets are displayed.

                   Advanced Content Displays the project’s Advanced Content assets, which
                   can include archives or individual files. When the Advanced Content tab is
                   selected, use the Show pop-up menu (Show All, Show Directories, Show
                   Archives, or Show Files) to determine which of these assets are displayed.

                3 Click the Import Media button to import an asset to the current tab in the
                  Palette window.

                4 To display the assets as thumbnails, click the View Thumbnails button.




                5 To display the assets in a list with attributes, click the View Details button.
                  Click the column heads to sort by attribute (Name, Type, Duration, Size, Date
                  Modified, Dimensions, and Location); click the column head again to sort in
                  reverse order.




                6 To get info on an asset, right-click the asset and choose Properties from the
                  Shortcut menu. A Properties window opens and displays properties for the
                  asset. Click OK to close the Properties window.

Adding subpictures
Scenarist Advanced Content supports two varieties of subtitle scripts:

• Scenarist Subtitle Script (*.sst or *.scn-sst), which references a separate
  graphics file for each subtitle

• Encoded Subtitle Script (*.sp_tbl), which references a single encoded SPU
  data file (*.sp_dat)

Using a Scenarist Subtitles (SST) script, you can import a series of 2-, 8-, or 32-bit
PNG image files into a Subpicture track. During the import process, any graphic
files that are not already 8-bit will be color-reduced to 8-bit.

Note: No changes are made to your source files.

An SST script is a text file with a .sst-scn extension that references PNG image
files and tells Scenarist Advanced Content the start frame and end frame for each
image. For information on creating SST scripts, refer to the Scenarist Subtitle
Script Format document, which is installed in the Documentation folder within
the application folder.

The following PNG files are supported:

• 32-bit with transparency (alpha transparency)

• 8-bit with transparency per pixel (index transparency)

• 2-bit with transparency per pixel (index transparency)

If you use an Encoded Subtitle Script, the script and data file must be in the same
folder and have the same root file name. The script contains the timing
information of each SPU, and the data file contains the individual SPU files.

Scheduled Events
       Scheduled events give you fine control over player behavior. You can set up a
       scheduled event, have a script look for the event, and then have the script
       initiate an action if the event is found. For example, if you want the player to
       return to the start of a movie but not reload an advanced application, you can
       place a scheduled event just before the end of the Title that makes the script
       jump back to the start. And if you add a scheduled pause immediately after this
       event, the script that does the Title jump can test the player’s state, and if it is
       paused, start playing again from the start, thus avoiding the reloading of the
       advanced application.

Audio and subpicture mapping
                  Note: In the following description, keep in mind that the term “stream” refers
                  to the EVOB and “track” refers to the Title.

                  For each EVOB clip in a Title, you can map audio and subpicture streams in the
                  EVOB to Title tracks. Often, the order of streams in the EVOB and the user-
                  viewable track list will match, i.e., they will both be in numeric order, 1, 2, 3, 4
                  and so on.

                  At times, however, tracks might require special mapping because of the
                  following:

                  • EVOB streams must be contiguous and start from 1. Therefore, if you have
                    only one EVOB stream, French, and for some reason you want the French
                    audio to be listed as Track 3 in the track navigation list, you would have to
                    map EVOB stream 1 to Track 3 in the Attributes window.

                  • EVOB Segments can be reused in various Titles. Therefore, it is possible that
                    you might want to map what the user would view as audio Track 1 to EVOB
                    audio stream number 2 and the user’s Track 2 to EVOB audio stream 8. In one
                    Title, for example, French might be track 3 and in another Title it might be
                    track 2, but both Titles could use the same EVOB Segment.

                  Note: Although EVOB streams can be mapped using the pulldowns in the
                  Attributes window, Advanced Subtitle clips must be placed in the exact same
                  numbered tracks in the Title Timeline window as those listed in the Track
                  Navigation List dialog.

                    available.

                    the Project Size field.

See also B-picture, chapter, I-picture, P-picture, sequence header.

GOP size Number of frames in a group of pictures (GOP). For example, a GOP
size of 10 looks like this if the I-, B-, and P-pictures contain whole frames:

   IBBPBBPBBP

and like this if the I-, B-, and P-pictures contain fields:

   IPBBBBPPBBBBPPBBBBPP

See also field, frame.

GOP structure The number of B-pictures before each P-picture in a group of
pictures. Typical GOP structures are I B P (one B-picture) and I B B P (two B-
pictures).

Hz (Hertz) Cycles per second. Unit of measurement for frequencies.

I-picture (Intra-Picture) MPEG video picture that contains all of the information
necessary to create a single frame or field. Every GOP in an MPEG video stream
starts with an I-picture, which provides a reference point for the B- and P-pictures
in the GOP. See also B-picture, GOP, P-picture.

I420 The FOURCC code for a compressed YUV color format developed by Intel
Corporation. Identical to IYUV.

IFO file One of the files on a DVD-Video disc. The IFO file contains instructions
that tell the DVD player how to play the VOB files on the disc. Because the disc
could become unplayable if the IFO file is damaged, a backup copy with the
extension .BUP is always included in a separate location on the disc.

               interleaved scanning Method for displaying an analog video signal on a television
               screen. This method was developed because video images flicker when displayed
               on televisions at 25 or 29.97 frames per second, where each frame fades away
               before the next one appears.

               To prevent flickering, each video frame is divided into two fields. One field
               contains the odd-numbered scan lines in the frame (the “top” field); the other
               contains the even-numbered scan lines (the “bottom” field). The television
               displays one field (one set of lines), followed by the next, at 59.94 fields per
               second for NTSC or 50 fields per second for PAL. At these frequencies, human
               persistence of vision causes the fields to be perceived as a single image.

               Compare with progressive scanning.

               ISO 9660 Specifies the naming convention for computer filenames. Level 1 limits
               filenames to eight characters plus a three-character extension using uppercase A
               to Z, digits 0 to 9, and the underscore “_” character; known as the “8.3” or MS-
               DOS format. Level 2 allows names of up to thirty characters, using all ASCII
               characters.

               IYUV See I420.

               Jacket Picture A picture that is displayed onscreen when the disc is stopped in a
               player that supports the Jacket Picture format.

               Joliet Extension to the ISO 9660 file system that allows long file names, and
               filenames with spaces and international characters. Available with Windows 95
               (or later) and Windows NT.

               JPEG Lossy compressed bitmap image file format developed by the Joint
               Photographic Experts Group. Files have the extension .jpg or .jpeg.

               k Standard abbreviation for 1,024 (210). Used as a prefix in measurements of
               computer bytes.

               K Standard abbreviation for 1,024 (210). Used as a prefix in measurements of
               computer bytes.

               KB (Kilobyte) 1,024 (210) bytes.

kbps (Kilobits per Second) Unit of measurement for data rates.

key frame MPEG video picture containing the entire contents of a single frame
(or field). An I-picture is a key frame.

kHz (Kilohertz) 1,000 cycles per second. Unit of measurement for frequencies.

letterbox Method for displaying widescreen (16:9) material on a standard (4:3)
television screen. The entire image is displayed in its proper aspect ratio across
the center of the screen. Horizontal black bars (mattes) are added to the top and
bottom of the image to fill the gaps between the image and the top and bottom
edges of the screen. Compare with pan and scan.

lossless Compression methods that do not discard any data. Compare with lossy.

lossy Compression methods that discard some data to achieve high compression
levels.

M Standard abbreviation for mega (million). When used in units of measurement
such as bits or Hertz, it means one million (1,000,000 or 106). When used for
measuring bytes of computer data, it means 1,048,576 or 220.

MB (Megabyte) 1,048,576 (220) bytes. Unit of measurement for computer data.

Mbps (Megabits per Second) Unit of measurement for data rates.

menu Screen containing buttons that link to specific locations in a DVD-Video
presentation. The viewer must select a button, then activate it to display the
linked material.

MHz (Megahertz) 1,000,000 cycles per second. A unit of measurement for
frequencies.

motion menu A DVD menu that has a video background or animated button
images.

MPEG Set of standards for compressing video and audio, developed by the
Moving Pictures Expert Group. The DVD-Video standard is based on MPEG-2
video compression; the standard also permits the use of MPEG-1 video.
154 Glossary



               multiplex To combine separate video and audio streams together into a single
               data stream. Often abbreviated to mux.

               NTSC (National Television Systems Committee) Television standard used in the
               United States, Canada, Japan, and other countries. NTSC television uses 525 scan
               lines (480 lines contain picture information) transmitted at 29.97 frames (59.94
               fields) per second. Compare with PAL.

               open GOP Group of pictures whose B- and P-pictures can reference pictures
               from another GOP. MPEG streams with open GOPs cannot be edited. Compare
               with closed GOP.

               P-picture (Predictively Coded Picture). MPEG video picture that contains only
               the information that is different from previous frames or fields. Each P-picture
               provides a reference point for B-pictures and subsequent P-pictures in a GOP. See
               also B-picture, GOP, I-picture.

               PAL (Phase Alternate Line) Television standard used in Europe and most of the
               rest of the world. PAL television uses 625 scan lines (576 are used for picture
               information) transmitted at 25 frames (50 fields) per second. Compare with
               NTSC.

               pan and scan Method for displaying widescreen (16:9) video on a standard (4:3)
               television screen. The widescreen image is cropped to fit the 4:3 aspect ratio.
               Compare with letterbox.

               PCM (Pulse Code Modulation) Uncompressed digital audio format. The quality of
               PCM audio depends both on the sample rate (a 48 kHz sample rate is better than
               44.1 kHz) and on the sample size (16-bits per sample is better than 8-bits).

               PICT Image file format developed by Apple Computer, Inc.

               pixel One of the dots that makes up a digital image. The resolution of an image
               is measured in pixels (width x height).
                                                                                  155



pixel aspect ratio Ratio between a single pixel’s width and its height. This is
usually expressed as a decimal number.

Pixels on a computer monitor are square and have a pixel aspect ratio of 1. Pixels
on a television screen are rectangular: on a standard NTSC television, each pixel
is slightly taller than it is wide, with an aspect ratio of 0.9; on a standard PAL
television, each pixel is slightly wider than it is tall, for a pixel aspect ratio of
1.0666. This is why standard NTSC and PAL televisions have the same 4:3 aspect
ratio even though they use a different number of scan lines.

For widescreen (16:9) televisions, the pixel aspect ratios are 1.2 for NTSC and
1.4222 for PAL.

PNG (Portable Network Graphic) Lossless compressed bitmap image file format.
Files have the extension .png.

program stream Stream containing multiplexed video and audio. Compare with
elementary stream.

progressive scanning Method for displaying a video signal on a computer
monitor (and on high-definition television). In a progressive scanning system,
each scan line is displayed in sequence. To prevent flicker, the scanning
frequency must be twice that of a standard television, but this produces a higher
quality picture. Compare with interlaced scanning.

resampling Process of converting a digital image from one resolution (size) to
another.

resolution Size (width by height) of a digital image, measured in pixels.

RGB The red-green-blue color model used in computer monitors. The color of
each pixel in an image is made up of a red component, a blue component, and a
green component, because these are the three colors that the human eye can
perceive. In a full-color (24 bits per pixel) image, each component can be one of
256 values, from zero (darkest) to 255 (lightest). If all three components have a
value of zero, the pixel is perceived as black. If all three components have a value
of 255, the pixel is perceived as white. Compare with YUV.
156 Glossary



               sample rate Number of times per second that a digital sample is taken of an
               analog audio source. Expressed in kHz. The sample rate for audio CDs is 44.1
               kHz; for DVD-Video, the sample rate is 48 kHz. Higher sample rates result in a
               more accurate reproduction of the original sound.

               sample size Number of bits allocated to each digital sample of an analog audio
               source. Larger sample sizes result in greater dynamic range and better
               reproduction of the original sound. DVD-Video uses sample sizes of 16, 20, or 24
               bits.

               SECAM (Sequential Color with Memory) A television transmission standard
               similar to PAL. The DVD-Video standard does not support SECAM, so DVD players
               in SECAM countries play PAL-format discs and transcode the signal to SECAM.

               sequence header Part of an MPEG video stream. Contains information about the
               video stream, such as aspect ratio, bit rate, picture resolution, and frame rate.
               The DVD Specification requires a sequence header before every GOP.

               set-top player Consumer DVD player designed for use with a television as part of
               a home theater system.

               stream Data that must be read and processed in a linear sequence, such as digital
               video and audio. Also known as a track.

               Targa Bitmap image file format developed by Pinnacle Systems, Inc. Files have
               the extension .tga, .vda, .icb, or .vst.

               thumbnail Small picture representing the contents of a video or still image file.

               TIFF (Tagged Information File Format) A versatile bitmap image file format. Files
               have the extension .tif or .tiff.

               timecode Location of a video frame relative to the start of the video clip.
               Timecode values generally use the format hh:mm:ss:ff
               (hours:seconds:minutes:frames).

               See also drop-frame timecode, non-drop-frame timecode.

               Title Generic term for a movie or slideshow.

transcode To convert digital video or audio data from one format to another, for
example, from AVI to MPEG.

transition The change from one video clip to another. This can be abrupt—one
clip finishes and the other one starts—or can involve digital effects such as fading
the end of the first clip into the beginning of the second clip.

trim To edit a video or audio clip to remove unwanted material from the
beginning or end.

UDF (Universal Disc Format) Standard developed by the Optical Storage
Technology Association for creating discs that can be used in any computer or
digital device.

UYNV See UYVY.

UYVY FOURCC code for a YUV color format used by many video capture cards.

V422 See YUY2.

VBR encoding (Variable Bit-Rate Encoding) A method of encoding MPEG video
streams by allocating more bits to complex sections of video and fewer bits to
less-complex sections. This results in higher quality video than CBR encoding at
the same overall bit rate, or the same level of quality as CBR encoding at a lower
overall bit rate. Compare with CBR encoding.

VIDEO_TS File directory on a DVD disc (or in a DVD Volume folder) where DVD-

VOB file (Video Object File) Basic media file, containing video and audio, of the

WAV audio Uncompressed or compressed digital audio format developed by
Microsoft Corporation. Files have the extension .wav.

widescreen Video displayed at a 16:9 ratio.
